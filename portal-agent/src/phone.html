Add Fabsy Admin to your phone

iPhone: open this page in Safari, tap Share → Add to Home Screen. Name it “Fabsy Admin”. Keep “Open as Web App” enabled. Open the new icon, sign in, tap “Enable notifications on this device”, and allow notifications.

Android: open this page in Chrome, open the menu → Add to Home screen → Install. Open Fabsy Admin and enable notifications.

The shortcut opens this page. It never runs or submits an action just by opening it.

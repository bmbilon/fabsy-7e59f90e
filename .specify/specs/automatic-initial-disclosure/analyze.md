# Coverage

Admission covers payment arriving before or after consent. Existing eligibility is reused, including staff-state, refund/dispute, canonical-case and receipt gates. Material checks bind the original ticket and electronic acceptance. Session acceptance is administrator-only and bound to the browser, ticket/action scope and terms hash. The adapter uses observed official form controls and holds additional declarations. Completion requires the exact-ticket receipt. Separate committing and retry rules prevent repeated writes. Deployment leaves unrelated workspace changes and paid campaigns untouched.

Lookup coverage includes plate/DL/DOB, invalid or missing values, a changed source, revoked records, exact upload capability, failed client saves, explicit staff confirmation, clipboard failure and stale case responses. Checkout stays unavailable until this upload has a saved identifier. The receipt's success sentence must itself name the exact ticket; an unrelated navigation header is insufficient. Unicode name comparisons retain letters instead of collapsing non-ASCII names. Live source verification is distinct from a government filing receipt.

Required-identifier coverage extends to the universal both/consent/payment paths and private signed-ticket path. PostgreSQL tests execute the actual database insert gates and protect private evidence/capability ownership, report-only orders and historical paid reconciliation. Runtime tests confirm each identifier is sufficient, invalid/unconfirmed inputs stop before an order/payment call, failed writes preserve retryable input, and raw identifiers never enter sessionStorage or URLs. Order imports reject ambiguous cases, changed claim hashes and email-only bindings. Existing legal filing and receipt gates remain unchanged.

Separate consent/payment orders do not create a second case. Their consistent lookup records can supply one identifier for the same exact ticket; conflicting values of the same kind hold for review. Once a case confirmation exists, it remains the selected source and keeps its current path/hash checks.
